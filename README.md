# formularios-angular
Ejemplos de formularios realizados mediante "Template" o "Data"

## Instalar Dependencias
Ejecutar en terminal comando: `pnpm install`

## Iniciar proyecto
Para trabajar con el formulario "template" , descomentar el tag <app-template> y comentar el tag <app-data>. Hacer lo inverso si se quiere trabajar con el formulario "data".

Ejecutar en terminal el comando `pnpm start` e introducir en el navegador `http://localhost:4200/` o ejecutar `pnpm start -- -o` y se abrira automaticamente en el navegador.

## Lint
Ejecutar `pnpm run lint` para comprobar el código con ESLint, o `pnpm run lint:fix` para corregir automáticamente lo que sea posible.

## Ayuda
Para mas informacion, ejecutar el comando `pnpm exec ng help` en el terminal o ir a [Angular CLI README](https://github.com/angular/angular-cli/blob/master/README.md).

Este proyecto se generó originalmente con [Angular CLI](https://github.com/angular/angular-cli) version 8.3.23, y se migró a Angular 17 + pnpm + ESLint el 2026-06-17.
